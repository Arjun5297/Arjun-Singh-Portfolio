
# Arjun Singh Portfolio

Personal portfolio for a Quality Automation Engineer / SDET.

## Features

- Responsive professional portfolio
- QA automation skills and experience
- SFP, DataX, and Teletrack project highlights
- Google Cloud Generative AI Leader certification
- QA Automation Hub LinkedIn page
- Contact information and education

## Requirements

- Node.js
- npm

## Run locally on Windows

Open PowerShell in your project folder and run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite in your browser.

## Production build

```powershell
npm.cmd run build
```

The production output will be generated in the `dist` folder.

## Profile photo

Copy your professional photo to:

`public/assets/profile.png`

## Personal LinkedIn

Update the `linkedinProfile` value in `src/App.jsx` with your actual profile URL.

## Hosting

The site can be deployed to GitHub Pages or another static hosting provider.
